# Система мониторинга воздушного пространства (Sky Tracker)

Курсовая работа по сбору данных из открытых API и анализу в БД PostgreSQL.

## Как запустить проект

1. **Клонируйте репозиторий:**
   ```
   git clone https://github.com/SRUNABEGU/Project2
   cd Project2_Plane_Tracker
2. **Установите зависимости:**\
    Если вы используете Poetry:
    ```
    poetry install
    ```
    Или через стандартный pip:
    ```
    pip install -r requirements.txt
    ```
3. **Настройте базу данных:**

        Создайте в PostgreSQL базу данных с именем sky_tracker.

        Настройте параметры подключения в блоке DB_CONFIG файла main.py.

4. **Запуск:**
    ```python main.py```

### Функционал программы

    Автоматический сбор данных о самолетах по 10 европейским странам.

    Интерактивный поиск самолетов в небе конкретной страны.

    Вывод Топ-N самых высоколетящих бортов.

    Фильтрация данных и встроенная SQL-аналитика (средняя скорость, поиск по ключевым словам).
